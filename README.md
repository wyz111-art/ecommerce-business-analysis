# 电商经营分析与增长诊断

> 基于 Python、SQL Server 与 Tableau 搭建端到端电商数据分析流程，围绕经营表现、商品结构、营销渠道、用户价值及 A/B 实验评估形成可落地的增长建议。

## 项目概览

本项目基于 2021 年 1 月至 2023 年 12 月的电商业务数据，完成了从原始数据清洗、指标建模、专题分析到可视化呈现的完整分析闭环。

项目重点回答以下业务问题：

1. 平台整体经营表现如何，增长由订单量、购买用户数还是客单价驱动？
2. 不同商品品类对 GMV 的贡献有何差异，平台是否存在品类依赖？
3. 新老用户的收入结构如何变化，存量用户是否逐步成为增长核心？
4. 不同获客渠道带来的用户质量是否存在显著差异？
5. 如何通过 RFM 模型识别高价值、潜力及流失风险用户？
6. 实验方案是否改善跳出、加购和购买转化表现？

## 技术栈

| 环节 | 工具 | 主要工作 |
| 数据处理 | Python、Pandas、NumPy | 缺失值处理、重复值检查、异常值过滤、字段标准化、探索性分析 |
| 数据存储 | SQL Server、SQLAlchemy、PyODBC | 清洗数据入库、业务表关联、指标宽表构建 |
| 数据建模 | T-SQL | 月度经营指标、品类/活动贡献、新老用户收入、渠道质量、RFM 分层 |
| 统计检验 | SciPy、Statsmodels | 卡方检验、比例 Z 检验、Bonferroni 校正、单因素方差分析 |
| 数据可视化 | Tableau | 经营趋势、品类贡献、营销活动、新老用户结构及转化漏斗 |

## 数据概况

项目包含 5 张核心业务表，清洗后共保留约 219 万条明细记录。

| 数据表 | 粒度 | 清洗后记录数 | 关键字段 |
| `customers` | 用户 | 100,000 | 注册日期、国家、年龄、性别、会员等级、获客渠道 |
| `products` | 商品 | 2,000 | 品类、品牌、基础价格、上市时间、高端商品标记 |
| `campaigns` | 营销活动 | 50 | 渠道、营销目标、目标客群、预期提升 |
| `events` | 用户行为事件 | 2,000,000 | 会话、事件类型、设备、流量来源、页面类型、实验组 |
| `transactions` | 交易明细 | 89,974 | 订单、商品、数量、折扣、GMV、活动、退款标记 |

数据时间范围为 **2021-01-01 至 2023-12-31**。

## 分析流程

```
["原始业务数据"] --> ["Python 清洗与 EDA"] --> ["SQL Server 数据库"] --> ["SQL 指标建模"] --> ["Tableau 经营看板"] --> ["A/B 实验检验"] --> ["业务洞察与策略"]
```

### 1. Python 数据清洗

使用 Pandas 对 5 张原始表进行统一清洗与质量检查：

- 将不涉及具体商品的行为事件缺失 `product_id` 标记为 `no_product`；
- 比较设备类型缺失组与非缺失组的事件分布，将缺失设备标记为 `unknown`，避免直接删除造成样本偏差；
- 删除缺少 `product_id` 的无效交易记录；
- 检查并处理完全重复记录；
- 将用户年龄限制在 10—120 岁；
- 过滤负数商品价格、负数会话时长、非正向购买数量和负数收入；
- 统一日期字段格式，并从交易时间中派生 `year`、`month` 等分析字段；
- 将清洗后的业务表写入 SQL Server，为后续指标建模提供标准化数据源。

### 2. 探索性数据分析

清洗阶段同步完成基础 EDA，用于理解数据分布并识别潜在异常：

- 营销渠道、营销目标及目标客群分布；
- 用户会员等级、年龄、性别和获客渠道分布；
- 不同会员等级下的用户结构差异；
- 24 小时用户行为事件分布；
- 商品品类、品牌及价格字段检查；
- 订单收入、购买数量、折扣及退款字段检查。

### 3. SQL 指标建模

通过 CTE、条件聚合、窗口函数及分位数函数构建 6 张分析宽表。

| 指标表 | 分析用途 | 核心指标 |
| `operation_kpi` | 月度经营表现 | GMV、有效收入、订单量、购买用户数、客单价、连带率、折扣订单占比、退款率 |
| `month_category_kpi` | 品类贡献分析 | 品类 GMV、销售件数、订单量、购买人数、GMV 占比 |
| `month_campaign_kpi` | 营销活动分析 | 活动 GMV、活动收入贡献、订单量、购买人数 |
| `user_type_revenue` | 新老用户结构 | 新老用户 GMV、有效收入、订单量、收入贡献率 |
| `channel_user_quality` | 获客渠道质量 | 首购转化率、买家人均收入、复购率、高价值用户占比 |
| `user_rfm_segment` | 用户价值分层 | R、F、M 指标、平均订单金额、复购标记、用户分层 |

其中：

- **GMV**：`SUM(gross_revenue)`
- **有效收入**：未退款订单的收入之和
- **客单价**：有效收入 / 购买用户数
- **连带率**：有效订单商品件数 / 有效订单数
- **品类贡献率**：品类 GMV / 当月总 GMV
- **高价值用户**：有效收入高于全体买家平均水平的用户

## 核心分析结果

### 1. 整体经营：规模稳定，但缺乏持续增长动能

三年累计实现：

| 指标 | 结果 |
| 累计 GMV | 8,630,269.31 |
| 累计订单数 | 89,974 |
| 累计购买用户数 | 58,987 |
| 累计销售件数 | 124,288 |
| 整体折扣交易占比 | 39.89% |

年度 GMV 从 2021 年的 289.88 万下降至 2023 年的 285.48 万，三年整体保持在相近规模，但连续两年小幅下降：

| 年份 | GMV | 订单数 | 购买用户数 |
| 2021 | 2,898,775.91 | 30,250 | 26,029 |
| 2022 | 2,876,743.17 | 29,713 | 25,586 |
| 2023 | 2,854,750.23 | 30,011 | 25,837 |

订单量和购买用户数整体波动有限，月度客单价大多处于 91—102 区间，说明平台尚未形成由用户规模或客单价驱动的明确增长趋势。

月度表现具有明显季节性：11 月 GMV 较 10 月分别增长 **25.16%（2021）**、**23.43%（2022）** 和 **25.13%（2023）**，12 月继续维持全年高位；次年 1 月则出现明显回落。经营增长较依赖年末促销节点。

### 2. 商品结构：电子产品是核心收入来源

| 品类 | 累计 GMV | GMV 占比 |
| Electronics | 3,554,175.61 | 41.18% |
| Home | 2,053,954.96 | 23.80% |
| Fashion | 1,338,781.78 | 15.51% |
| Sports | 1,000,708.47 | 11.60% |
| Beauty | 381,439.05 | 4.42% |
| Grocery | 301,209.44 | 3.49% |

电子产品与家居品类合计贡献 **64.98%** 的 GMV，是平台最主要的收入来源。其中电子产品 GMV 占比达到 41.18%，明显高于其他品类，平台存在一定的单一品类依赖。

值得注意的是，Grocery 的累计销量为 19,335 件，但 GMV 占比仅为 3.49%，表现出高频低客单特征；该品类更适合作为拉动购买频次和跨品类连带的入口，而非直接承担收入增长目标。

### 3. 用户结构：收入重心由拉新逐步转向存量经营

按用户首次交易所在自然月重新校验后，新用户贡献的年度收入由 2021 年的 253.11 万下降至 2023 年的 135.53 万；同期老用户收入由 36.77 万增长至 149.95 万。

2023 年 12 月，老用户贡献 17.54 万收入，占当月 GMV 的 **58.60%**，已经超过新用户的 41.40%。这表明平台收入结构逐步从新客驱动转向存量用户驱动，复购与用户生命周期管理的重要性持续上升。

### 4. RFM 分层：少量核心用户贡献较高收入

以数据集最后交易日期为观察基准，使用：

- **R（Recency）**：距最近一次购买的天数；
- **F（Frequency）**：有效订单频次；
- **M（Monetary）**：累计有效收入。

基于 R/F/M 高低组合将用户划分为高价值、潜力、新用户、一般、流失风险和沉睡用户。

| 用户分层 | 用户数 | 用户占比 | 收入贡献率 | 典型特征 |
| 高价值用户 | 12,535 | 21.25% | 39.46% | 活跃、购买频次与累计消费均较高 |
| 流失风险用户 | 7,775 | 13.18% | 21.38% | 历史价值高，但距最近购买时间较长 |
| 沉睡用户 | 21,718 | 36.82% | 21.25% | 长期未购买，历史消费与频次整体偏低 |
| 潜力用户 | 4,395 | 7.45% | 9.85% | 近期活跃、消费金额较高，但频次不足 |
| 新用户 | 9,742 | 16.52% | 5.70% | 近期首购，仍需完成后续转化 |
| 一般用户 | 2,822 | 4.78% | 2.36% | 近期活跃且有一定频次，但消费金额偏低 |

高价值用户仅占 21.25%，却贡献 39.46% 的收入；流失风险用户占 13.18%，贡献 21.38% 的历史收入。相比无差别促销，优先维护高价值用户并召回流失风险用户具有更高的投入产出潜力。

### 5. 获客渠道：规模存在差异，用户质量整体接近

在获客渠道中，Paid Search 与 Organic 的注册用户规模最大，均接近 3 万人。各渠道首购转化率集中在 58.45%—59.23%，复购率集中在 38.18%—38.70%，差异较小。

- **Paid Search** 首购转化率最高，为 59.23%；
- **Referral** 复购率最高，为 38.70%，高价值用户占比最高，为 36.09%；
- **Email** 买家人均收入最高，为 147.66；
- **Social** 的首购转化率、买家人均收入及高价值用户占比相对偏低。

因此，渠道评估不应只关注注册规模，还应联合首购、复购、用户价值与获客成本进行判断。当前数据未提供渠道成本，无法进一步计算 CAC、ROAS 或增量 ROI。

### 6. 营销活动：需补充成本与归因信息

已归因活动中，Affiliate 和 Paid Search 的累计 GMV 相对较高；但约 **20.22%** 的交易 GMV 未匹配到具体营销活动。

现有数据可以比较渠道及活动的收入贡献，但由于缺少曝光、点击、实际投放成本和增量对照信息，不能仅凭 GMV 判断活动效率。后续应建立统一归因规则，并补充成本字段后计算 ROAS、CAC 和增量收入。

### 7. A/B 测试：实验版本显著提升购买转化，Variant B 提升最明显

以会话为分析单位，对 Control、Variant A 和 Variant B 三组进行比较：

| 实验组 | 会话数 | 跳出率 | 加购率 | 购买转化率 | 平均会话时长（秒） |
| Control | 1,198,390 | 9.56% | 14.26% | 4.74% | 130.75 |
| Variant A | 401,411 | 9.50% | 14.22% | 5.24% | 130.56 |
| Variant B | 400,181 | 9.29% | 14.08% | 6.30% | 130.40 |

统计检验结果：

- 三组购买转化率存在显著差异（卡方检验，`p < 0.001`）；
- 经 Bonferroni 校正后，三组购买转化率的两两差异均显著（校正阈值 `α' = 0.0167`）；
- 三组加购率总体存在显著差异（卡方检验，`p = 0.0196`）；
- 加购率的两两比较中，仅 Control 与 Variant B 的差异在 Bonferroni 校正后显著（`p = 0.0051`）；Control 与 Variant A（`p = 0.5628`）、Variant A 与 Variant B（`p = 0.0688`）均不显著；
- 平均会话时长不存在显著差异（单因素 ANOVA，`p = 0.4439`）。

从业务结果看，Variant A 的购买转化率较 Control 提升 `0.50` 个百分点，相对提升约 `10.55%`；Variant B 较 Control 提升 `1.56` 个百分点，相对提升约 `32.91%`。Variant B 同时显著优于 Variant A，是三组中购买转化表现最好的版本。

需要注意的是，Variant B 的加购率为 `14.08%`，较 Control 低 `0.18` 个百分点，且两组差异显著；其购买转化提升并未伴随加购行为同步增长。Variant A 的加购率与 Control 无显著差异，购买转化提升幅度则相对有限。三组平均会话时长没有显著差异，说明页面停留时长并非购买转化变化的主要驱动因素。

综合判断，Variant B 是购买转化表现最优的方案，但上线前应进一步确认“加购率下降、购买率上升”的漏斗变化是否符合页面改版机制，并补充订单收入、客单价等结果指标，判断购买率提升能否转化为实际收入增长。若随机分流、实验同期性和转化归因等前置条件均成立，可优先对 Variant B 进行灰度上线，并持续监测加购率、购买转化率及收入指标。

## Tableau 看板设计

Tableau 看板将分析结果整合为四类视图：

1. **经营核心指标**：GMV、有效收入、有效订单量、购买用户数、客单价、人均购买频次及环比变化；
2. **商品与活动结构**：品类 GMV 趋势、品类贡献率、渠道及营销目标表现；
3. **用户结构**：新老用户 GMV 趋势与收入贡献占比；
4. **行为转化**：浏览、加购、购买用户数，浏览至加购、加购至购买转化率及跳出率。

看板支持按年份、月份及业务维度进行筛选，用于快速定位经营变化及结构性问题。

## 业务建议

### 1. 从规模增长转向结构增长

平台三年 GMV 基本稳定但未持续上升。建议将增长目标拆分为购买用户数、购买频次、客单价和品类结构四个驱动因素，按月监控贡献变化，避免只跟踪总 GMV。

### 2. 降低核心品类依赖

保持电子产品与家居品类的收入优势，同时利用 Grocery 的高频属性设计跨品类组合购、满额加购和会员任务，引导用户向高客单品类迁移。

### 3. 建立分层用户运营机制

- 高价值用户：提供会员权益、优先购和专属服务，重点控制流失；
- 流失风险用户：结合历史偏好进行定向召回，控制优惠成本；
- 潜力用户：通过二次购买激励和关联推荐提升购买频次；
- 新用户：围绕首购后的关键周期设计二购转化策略；
- 沉睡用户：先开展小样本召回测试，再依据增量收益决定是否扩大投入。

### 4. 优化渠道评价体系

当前各获客渠道的用户质量差异不大，应补充成本数据，建立“注册—首购—复购—高价值—收入”的完整渠道漏斗，并以 CAC、LTV/CAC 和回收周期替代单一注册量指标。

### 5. 完善实验治理

正式实验应预先确定主指标、护栏指标、最小可检测效应和样本量；统一会话唯一键，检查样本比例失衡，并在显著性之外同步报告绝对提升、相对提升和置信区间。

## 数据质量与分析边界

- 清洗后的交易表中 `refund_flag` 全部为 0，因此当前“有效收入”等于 GMV，退款率不具备业务解释力；需要确认原始退款数据是否缺失或编码异常。
- 原 SQL 分别对 `year` 与 `month` 求最小值来识别首购月，可能在跨年订单中组合出并非真实存在的年月；本文的新老用户年度结果已改用完整交易月份的最小值重新校验，复现时应同步修正该 SQL。
- 活动分析缺少曝光、点击和成本字段，无法计算 ROAS、CAC 或增量 ROI。
- 用户渠道质量分析未纳入获客成本，不能据此直接制定预算分配方案。
- A/B 实验各组样本量不均衡，且存在 1 条异常实验组标签；正式决策前应依据预设分流比例完成 SRM 检查，并复核随机化与样本独立性。
- 本项目结论仅基于当前数据范围，不代表因果关系；营销与用户策略仍需通过增量实验验证。
